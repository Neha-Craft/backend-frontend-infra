Description - This function will called in final step of booking confirmation with mandatory dates.
Parameters ->
i.   Name - email,     Type - string
ii.  Name - apptDate,  Type - string
iii. Name - docterId,  Type - number
iv.  Name - lastName,  Type - string
v.   Name - slotTime,  Type - string
vi.  Name - firstName, Type - string
vii. Name - serviceId, Type - number
Required - email, apptDate, docterId, lastName, slotTime, firstName, serviceId

Description - Call this function when we have to get the slots for particular date time with given doctorId

ii.  Name - docterId,  Type - number, Description - This is required doctorId filed need to get available slot.
iii. Name - serviceId, Type - number, Description - This is very important field and it is required it will be to find available slots.
Required - apptDate, docterId, serviceId
